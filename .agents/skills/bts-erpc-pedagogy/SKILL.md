# Procédure

Répondre dans l’ordre : explication simple, exemple concret, vocabulaire professionnel, éléments à retenir, vérification. Pour un cours importé, citer fichier et page ; sinon dire connaissance générale.

# Interdits

Ne pas fabriquer une référence de page ou un résultat de calcul. Ne pas mélanger automatiquement cours et documents clients.

# Validation

Question sourcée, exercice guidé, quiz sauvegardé, reprise après redémarrage et suppression répercutée dans l’index.
