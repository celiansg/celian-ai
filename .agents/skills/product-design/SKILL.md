# Procédure

Lire `.21st/design.json` et les tokens existants, rechercher 21st.dev avant un composant complexe, réutiliser les primitives Agent Elements, puis tester clavier, mobile, empty/error/loading et reduced-motion.

# Principes

Les couleurs d’agents sont des accents. Les actions principales restent visibles. Les chiffres doivent venir de données réelles ; une absence devient une invitation explicite.
